# Pixel 螢幕即時翻譯 (Pixel Screen Translate)

這是一款專為 Windows 打造的桌面螢幕即時翻譯工具，設計概念源自 Google Pixel 手機的「智慧鏡頭／螢幕即時翻譯」功能：不僅提供定格快照原地翻譯，更具備**「滑鼠滾輪滾動時自動即時翻譯」**的極致跟隨體驗！

---

## ✨ 核心三大翻譯模式

### 1. 🖱️ 滾輪動態跟隨翻譯模式（Live Scroll Follow Mode，新登場！）
- **快捷鍵 <kbd>Ctrl + Alt + W</kbd> 隨時開啟／關閉**。
- **全視窗滑鼠穿透（Scroll-Through）**：覆蓋層不干擾你的操作，你可以自由地在瀏覽器、PDF 閱讀器、漫畫或社群平台中向下滾動滑鼠滾輪。
- **滾動停頓即時自動辨識**：內建 Windows 低階滑鼠監聽與智慧防抖（260ms），當滑鼠滾輪停下時，後台以毫秒級 Windows 原生離線 OCR 自動擷取新畫面並在原地覆蓋新內容的翻譯！
- **滾動平滑淡出**：滾動當下舊文字自動淡出，停止時新譯文浮現，閱讀完全不卡頓。

### 2. 📸 定格全螢幕快照翻譯（Snapshot In-Place Mode）
- **快捷鍵 <kbd>Ctrl + Alt + T</kbd>**。
- 凍結當前螢幕畫面，精確提取文字框座標（Bounding Box）。
- 智慧邊界色彩採樣遮蓋原文，自適應字級與高對比文字顏色。
- 滑鼠移至文字塊上方可查看「原文對照 Tooltip」，單擊文字塊直接複製譯文。

### 3. 📜 側邊滾動對照清單模式（Scrollable Sidebar Reader）
- 在螢幕右側展開毛玻璃抽屜面板，以滑鼠滾輪上下滾動瀏覽整頁辨識的所有段落清單。
- 支援原文／譯文關鍵字即時搜尋篩選，並可一鍵「📋 複製全部」導出全文。
- 在覆蓋層中**按下鍵盤 <kbd>Tab</kbd> 鍵**即可隨時在「原地覆蓋」與「側邊清單」間切換。

---

## ⌨️ 快捷鍵一覽

| 快捷鍵 | 動作 |
| :--- | :--- |
| **<kbd>Ctrl + Alt + W</kbd>** | **開啟 / 關閉「滾輪即時動態跟隨翻譯」模式**（邊滾動邊即時翻譯） |
| **<kbd>Ctrl + Alt + T</kbd>** | **定格快照翻譯**（拍下當前螢幕畫面進行原地翻譯） |
| **<kbd>Tab</kbd>** | 在覆蓋層中**一鍵切換**「📌 原地覆蓋」與「📜 側邊滾動清單」 |
| **滑鼠滾輪** | 在動態跟隨模式下直接滾動底層網頁；在側邊清單模式下捲動瀏覽卡片 |
| **<kbd>Esc</kbd>** | 立即關閉退出所有覆蓋層狀態 |

## 🚀 啟動與使用

### 開發模式啟動
```powershell
cd c:\Users\vincent\source\side_projects\pixel-screen-translate
npm run tauri dev
```

啟動後：
1. 切換到你想要閱讀的外語網頁、論文或漫畫。
2. 按下鍵盤 **`Ctrl + Alt + W`**（或在控制中心點擊「⚡ 啟動滾輪即時跟隨翻譯」）。
3. 用滑鼠滾輪上下滾動網頁，你會發現網頁滾動完全不受阻礙，且每次滾輪停頓時，畫面上的外語都會自動原地替換成正體中文！
4. 閱讀完畢隨時按 **`Ctrl + Alt + W`** 或 **`Esc`** 即可關閉退出。
