# Pixel 螢幕即時翻譯 (Pixel Screen Translate)

這是一款專為 Windows 打造的桌面螢幕即時翻譯工具，設計概念源自 Google Pixel 手機的「智慧鏡頭／螢幕即時翻譯」功能：按下快捷鍵後，程式會自動擷取螢幕畫面，以毫秒級的速度完成文字座標辨識，並提供「**原地貼平覆蓋**」與「**側邊滾動對照**」雙模式自由切換。

---

## ✨ 核心雙模式功能

### 1. 📌 Pixel 風格原地文字替換（In-Place Replacement）
- 提取文字框精確座標（Bounding Box）。
- 智慧邊界色彩採樣（Border Color Sampling），無痕覆蓋原始文字。
- 計算背景感知亮度（Luminance），自動套用黑／白高對比清晰文字與字級縮放。
- 滑鼠移至文字塊上方時浮動顯示「原文對照 Tooltip」。

### 2. 📜 側邊滾動對照清單（Scrollable Sidebar Reader，全新支援卷軸滾動）
- 在螢幕右側展開現代感十足的毛玻璃抽屜面板。
- **支援滑鼠滾輪上下平滑捲動**，將當前畫面識別出的所有段落以條列式清晰對照呈現（譯文主體 ＋ 原文輔助）。
- **關鍵字即時搜尋篩選**：可在側邊欄上方快速搜尋原文或譯文。
- **一鍵複製全部內容**：點擊「📋 複製全部」即可將整篇翻譯文字匯出至剪貼簿。
- **雙向聯動標記**：滑鼠移至側邊欄卡片時，螢幕左側對應的原始區塊會同步發光標記；點選螢幕上的區塊也會自動平滑滾動至對應卡片。

## ⌨️ 快捷鍵與操作

| 快捷鍵 / 操作 | 功能說明 |
| :--- | :--- |
| **<kbd>Ctrl + Alt + T</kbd>** | 在任何視窗/畫面中隨時進行全螢幕即時翻譯 |
| **<kbd>Tab</kbd>** | 在覆蓋層中**一鍵切換**「📌 原地覆蓋」與「📜 側邊滾動對照」模式 |
| **滑鼠滾輪（Scroll Wheel）** | 在「側邊滾動對照模式」下順暢上下滾動瀏覽所有翻譯卡片 |
| **滑鼠懸停（Hover）** | 原地模式下顯示原文 Tooltip；側邊模式下聯動高亮對應螢幕區塊 |
| **單擊文字塊 / 複製按鈕** | 自動複製該段譯文至剪貼簿 |
| **<kbd>Esc</kbd>** | 立即關閉退出透明覆蓋層 |
