# Pixel 螢幕即時翻譯 (Pixel Screen Translate)

這是一款專為 Windows 打造的桌面螢幕即時翻譯工具，設計概念源自 Google Pixel 手機的「智慧鏡頭／螢幕即時翻譯」功能：不僅提供全螢幕快照原地翻譯與「**滑鼠滾輪邊滾動邊即時翻譯**」，更具備**多行段落智慧合併**、**LRU 0ms 翻譯快取**與**滑鼠拖曳框選翻譯**三大深度優化！

---

## ✨ 核心四大翻譯模式

### 1. 🖱️ 滾輪動態跟隨翻譯模式（Live Scroll Follow Mode）
- **快捷鍵 <kbd>Ctrl + Alt + W</kbd>**。
- **全視窗滑鼠穿透（Scroll-Through）**：覆蓋層不干擾操作，自由在瀏覽器、PDF、漫畫或社群平台中滾動滑鼠滾輪。
- **滾動停頓即時自動辨識**：內建 Windows 低階滑鼠監聽與防抖，滾輪一動立即清空舊色塊，停頓 280ms 自動擷取乾淨畫面並原地覆蓋新翻譯。

### 2. ✂️ 區域滑鼠框選翻譯（Snipping Drag-to-Select Mode，全新升級！）
- **快捷鍵 <kbd>Ctrl + Alt + S</kbd> 或 <kbd>Alt + Shift + S</kbd>**。
- 按下後滑鼠化為十字準心，在畫面上拖曳圈選需要翻譯的矩形區域（如漫畫對話框、局部軟體彈窗、影片字幕）。
- 放開滑鼠自動辨識並將翻譯文字緊湊填滿在該圈選區域內！

### 3. 📸 定格全螢幕快照翻譯（Snapshot In-Place Mode）
- **快捷鍵 <kbd>Ctrl + Alt + T</kbd>**。
- 凍結螢幕畫面，自動進行**多行段落智慧合併**，平鋪覆蓋原文，保留版面排版。
- 滑鼠懸停顯示完整句子原文對照 Tooltip，單擊文字塊直接複製譯文。

### 4. 📜 側邊滾動對照清單模式（Scrollable Sidebar Reader）
- 在螢幕右側展開毛玻璃抽屜面板，以滑鼠滾輪上下滾動瀏覽整頁辨識的所有自然段落。
- 支援原文／譯文關鍵字即時搜尋篩選，並可一鍵「📋 複製全部」導出全文。
- 在覆蓋層中**按下鍵盤 <kbd>Tab</kbd> 鍵**即可隨時在「原地覆蓋」與「側邊清單」間切換。

## 🧠 六大效能與體驗優化

1. **⚡ 直通記憶體點陣圖（Zero-Compression Pipeline）**：
   - 截圖直接從記憶體 RGBA 點陣圖藉由硬體級指針互換轉至 `SoftwareBitmap`，完全省去每一影格耗損 50~80ms 的 PNG 編解碼與 CPU 負擔。
2. **🛡️ 請求併發控制與防節流（Semaphore Concurrency Control）**：
   - 內建 `tokio::sync::Semaphore(4)` 嚴格管制同時向翻譯端點發出的連線數，並具備 HTTP 429 智慧 Backoff 重試機制，杜絕 IP 暫時封鎖風險。
3. **🖥️ 游標感應多螢幕支援（Multi-Monitor Cursor-Aware Support）**：
   - 自動透過 Windows API 偵測滑鼠游標所在的顯示器，在副螢幕上看外語論文、PDF 或生肉漫畫時，覆蓋層自動跳轉精準覆蓋該螢幕。
4. **🪟 Windows 系統匣常駐（System Tray & Minimize to Tray）**：
   - 關閉主面板視窗時自動隱藏至右下角系統匣常駐，全域快捷鍵背景永遠待命；點擊系統匣圖示即可秒開控制台。
5. **🌐 Windows 離線 OCR 來源語系動態偵測**：
   - 自動檢測並列出系統內已安裝的所有 Windows 原生 OCR 語言包（例如日文 `ja-JP`、英文 `en-US`、韓文、德文等），大幅提升特殊外語的辨識準確率。
6. **多行段落智慧合併與 LRU 0ms 快取**：
   - 自動依據垂直行距、對齊邊界與句尾標點拼合完整自然段落；重複出現詞句 0 毫秒極速秒回。

## ⌨️ 快捷鍵一覽

| 快捷鍵 | 動作 |
| :--- | :--- |
| **<kbd>Ctrl + Alt + W</kbd>** | **開啟 / 關閉「滾輪即時動態跟隨翻譯」**（邊滾動邊即時翻譯） |
| **<kbd>Ctrl + Alt + S</kbd>** / **<kbd>Alt + Shift + S</kbd>** | **開啟「區域滑鼠框選翻譯」**（拖曳圈選漫畫對話框或局部區域，雙快捷鍵相容） |
| **<kbd>Ctrl + Alt + T</kbd>** | **定格全螢幕快照翻譯**（拍下當前螢幕畫面進行原地翻譯） |
| **<kbd>Tab</kbd>** | 在覆蓋層中**一鍵切換**「📌 原地覆蓋」與「📜 側邊滾動清單」 |
| **<kbd>Esc</kbd>** | **全域隨時退出**（無論鍵盤焦點在 Chrome 或任何程式，按 Esc 均立即關閉退出） |

## 🚀 啟動與使用

```powershell
cd pixel-screen-translate

npm run tauri dev
```

```powershell
npm run tauri build
```

## 🔒 隱私與安全說明

1. **本機離線 OCR 運算**：
   - 螢幕畫面辨識採用 Windows 10/11 內建的 `Windows.Media.Ocr` API，所有影像截圖與像素特徵分析均在**本機記憶體中完成**，絕不儲存截圖至硬碟，亦不外傳任何圖片檔案。
2. **文字翻譯資料傳輸**：
   - 辨識出的文字字串會透過 HTTPS 請求發送至公開翻譯端點進行翻譯。
   - **隱私提醒**：若螢幕上顯示密碼、金鑰、個人隱私資料或公司機密文件，請避免執行全螢幕或局部翻譯，以防止文字送出。
3. **低階鍵盤掛鉤（WH_KEYBOARD_LL）**：
   - 本專案僅在低階鍵盤掛鉤中針對 `Esc`（關閉翻譯覆蓋層）與 `Ctrl+Alt+S` / `Alt+Shift+S`（啟動框選翻譯）進行按鍵比對。
   - **絕無記錄、側錄、快取或外傳任何其他按鍵輸入**，程式碼完全開源可受檢驗。
